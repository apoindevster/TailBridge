# Home and PIN lock

Mode: Operate. Extend the existing native 480×320 touchscreen; keep its established neon theme.

## Direction contract

THESIS: A private touchscreen console with one clear hub: Lock, Status and Wi-Fi. The user explicitly specified these three actions and the existing theme.

OWN-WORLD: Inherit DESIGN.md's indigo surfaces, cyan headings, magenta primary actions, orange feedback, square controls, DejaVu fonts and static three-color rail. No new visual identity or decorative assets.

STORY: Set a private PIN during installation, unlock after startup, choose one of three home actions, return Home from Wi-Fi or Status, and lock before leaving the appliance. Tailscale traffic continues while the touchscreen is locked.

FIRST VIEWPORT: Locked shows a masked field and feedback on the left, a 3×4 numeric keypad on the right, and Unlock below the field. Home shows its heading above three full-width stacked buttons. All controls remain at least 42 px high.

FORM: Narrow user-specified extension; no concept seed or replacement-world exercise. Boot/restart requires the PIN; success opens Home. Missing setup and unavailable service fail closed. Six to twelve digits, private installer prompts, no production default.

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance

Evidence: synthetic native screenshots and tests; physical touch, kiosk escape and Pi PIN-entry timing remain unverified. Screenshots are generated by tests/ui_smoke.py and intentionally strip metadata for publication; provenance is documented alongside them.

## Verified implementation

The extension uses the incumbent palette, DejaVu typography, flat square button
states, persistent cyan credential outline and static console rail. Existing
primitives suffice; no new visual tokens or design identity are required.
`DESIGN.md` and `.impeccable/design.json` retain their visual tokens and identity;
their navigation prose and evidence list now include this extension.

- Home contains exactly Lock, Status and Wi-Fi, in that order. Its buttons are
  448 × 54 px; Lock uses the existing primary treatment. Wi-Fi and Status return
  to Home through the existing upper-right secondary navigation control.
- The lock screen places a 204 × 42 px masked readout on the left and a numeric
  keypad of 68 × 52 px controls on the right. Unlock is 204 × 48 px. These are
  surface-specific dimensions using the established button and readout language.
- Unlock becomes magenta only when a valid-length PIN can be submitted. Incorrect
  PIN and retry feedback uses existing orange text; missing setup and unavailable
  lock service retain the locked screen with disabled controls and SSH recovery
  guidance. No capture exposes the PIN digits.
